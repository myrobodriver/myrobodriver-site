# MyRoboDriver

Public marketing site for [myrobodriver.com](https://myrobodriver.com/). Static HTML and CSS, published with GitHub Pages from `main`.

MyRoboDriver is an independent ride service in Tesla vehicles, now serving Middle Georgia. The tagline is “The chauffeur everyone can afford.”

Every ride today has a safety driver in the car. Vehicles run Tesla’s FSD (Supervised), which needs active human supervision. Driverless rides are mentioned only in Safety, as a possible later step with no date.

The footer, About, and Safety say the company is not affiliated with, endorsed by, or sponsored by Tesla, Inc. Tesla and FSD are trademarks of Tesla, Inc.

Contact says ride requests and contact options are coming soon. The page does not publish an email address, a phone number, or a street address.
